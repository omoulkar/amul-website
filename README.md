# 🌸 Amul Kool Rose — Interactive 3D Scroll Showcase

An Apple-grade, high-performance canvas scroll animation and product landing page for **Amul Kool Rose (The Taste of India)**.

---

## ✨ Features

- **204 HD Frames Cinematic Sequence**: Smooth 1080p frame-by-frame scrubbing that animates a liquid rose milk splash and bottle reveal.
- **Physics Lerp Damping**: Damped linear interpolation via `requestAnimationFrame` for buttery-smooth scrubbing without stutter.
- **Responsive Cover Canvas**: Full viewport cover scaling preserving aspect ratios across mobile, tablet, and desktop monitors.
- **Hero Title Fade Transition**: Centered "Amul Kool — The Taste of India" title with smooth fade-out as the user scrolls past 30% of the animation sequence.
- **Transparent Frosted Navbar**: Floating glassmorphic header with smooth scroll links to each section (*Experience*, *The Craft*, *Nutrition*, *Recipes*, *Packs*, *Reviews*, *FAQ*).
- **Comprehensive Showcase Sections**:
  - **The Sensory Craft**: Damask rose extract, dairy silk, and balance meter.
  - **Pure Dairy Nutrition**: Calorie, protein, and calcium breakdown with comparison vs sodas.
  - **Mixology & Serving Rituals**: The Crushed Frost & Mint, Grand Royal Falooda Bowl, and Velvet Rose Milk Boba.
  - **Pack Selector & Delivery Widget**: Single bottle, 6-pack crate, and 24-pack options with an interactive 6-digit Indian pincode delivery checker.
  - **Customer Love**: Verified sipper testimonials.
  - **Interactive FAQ Accordion**: Expandable questions and answers.
  - **Brand Footer**: Social links, newsletter signup, and cooperative dairy credentials.

## 🛠️ Local Development

Clone the repository and run:

```bash
# Clone the repository
git clone https://github.com/omoulkar/amul-website.git
cd amul-website

# Run the local server
node server.js
# or
npm start
```

Open your browser and visit:
👉 **http://localhost:3000/**

## 🚀 Deploy to Vercel

This repository is pre-configured for instant zero-config deployment on Vercel:

1. Import this repository in your **[Vercel Dashboard](https://vercel.com/new)** (`omoulkar/amul-website`).
2. Framework Preset: **Other** (Static HTML).
3. Root Directory: `./` (default).
4. Click **Deploy**.

Vercel will automatically serve the static files and apply the long-term immutable caching rules configured in `vercel.json` for lightning-fast edge performance.
